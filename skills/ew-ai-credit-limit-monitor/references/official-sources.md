# Official Source Policy / 官方來源政策

There is no known permanent OpenAI bulletin dedicated solely to announcing future Codex resets. Do not invent one or imply that codex-resets.com is official.

## Trust hierarchy / 信任層級

### 1. ACCOUNT CONFIRMED / 帳號確認

Highest authority for the individual user:

- authenticated `Settings → Usage`;
- visible remaining allowance and scheduled reset time;
- visible banked reset count, type, expiry, and history.

Use this source for the user's actual eligibility and timing. General announcements do not override the account page.

### 2. OFFICIALLY CONFIRMED / 官方確認

Use these OpenAI-controlled sources for rules and confirmed announcements:

- `https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan`
- `https://help.openai.com/en/articles/20001271-codex-referral-promotions`
- `https://help.openai.com/en/articles/6825453-chatgpt-release-notes`

An official article may be updated after an event. Report its visible update date when relevant.

### 3. SERVICE STATUS ONLY / 僅供服務狀態

`https://status.openai.com/` is authoritative for service incidents and recovery. It is not a reset promotion calendar. Use it only when a usage display or service may be affected by an incident.

### 4. THIRD-PARTY SIGNAL / 第三方線索

`https://codex-resets.com/` tracks reset announcements and history but is not an OpenAI website. Use it for early detection and historical context only.

## Confirmation labels / 確認標籤

Every reported reset announcement must carry one label:

- `ACCOUNT CONFIRMED / 帳號確認`
- `OFFICIALLY CONFIRMED / 官方確認`
- `THIRD-PARTY SIGNAL — UNVERIFIED / 第三方線索—尚未獲官方確認`
- `CONFLICTING INFORMATION / 資訊衝突`

When sources conflict, show the conflict and follow the account page for the user's current allowance. Do not claim an unverified reset occurred merely because a third-party tracker says it propagated.

## Recommendation boundary / 建議邊界

Never recommend using a banked reset, buying credits, or changing work plans solely because of an unverified third-party signal. Base recommendations on account facts and official rules. Third-party intelligence may justify rechecking the account page, nothing more.
